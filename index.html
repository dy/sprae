FAQ

Why a library, when AI writes the code?

Agents can write sprae code easily. Sprae removes frontend build step from your pipeline – perfect fit for static sites.

Is evaluating attributes safe?

Expressions compile with new Function, same as any inline script. The CSP build provides safe execution without eval.

What if the script fails to load?

Sprae provides progressive enhancement, so the page falls back to your HTML. To hide FOUC, use [\:if],[\:each]{visibility:hidden}.

Does it have components?

For simpler cases, manage duplication with templates or includes. Custom elements can be made with define-element or any CE library: sprae sets their props and stops at their boundary. Coming from Alpine.data()? See the migration guide.

Who is it not for?

Apps that live in client state: routing, deep component trees, offline. Take a framework there. Sprae is for pages where a framework is overkill.

How do I debug an expression?

Expressions is plain JS, state is plain object. An error names the element and the expression in the console.

Is it production-ready?

3+ years of releases, no dependencies, tests across both compilers and alternative signals, any browser with Proxy.

Who maintains it?

Dmitry Iv, since 2022, under MIT. Independent, no company behind it.

Sprae is a lightweight alternative to Alpine.js and petite-vue: reactive HTML attributes with no build step, a CSP-safe build for browser extensions, and the same directives in JSX, Next.js server components, Markdown, and server templates.
